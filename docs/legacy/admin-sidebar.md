## Nama di aplikasi ini (2026-11-28)

Susunan grup dan urutan mengikuti tabel di atas. Nama menu disederhanakan ke bahasa sehari-hari atas arahan pemilik
("lebih ramah pengguna, jangan istilah bawaan AI"), misalnya: Penerimaan Biaya → **Keuangan Siswa**, Sistem Laporan → **Laporan**,
Pusat Bantuan & Pengaduan → **Pengaduan**, Pengelolaan Website → **Website Sekolah**, Saldo Ewallet Siswa → **Saldo Siswa**,
KASIR → **Kasir Kantin**, Boarding Pass → **Izin Pulang Asrama**, Pemetaan Alokasi Kas → **Alokasi Dana**,
Konversi & Demografi PPDB → **Pendaftar PPDB**, Atur Cabang → **Unit Sekolah**. Daftar lengkap ada di `App\Support\Navigation::catalog()`.
Halaman kita yang tidak punya padanan di aplikasi lama (mis. Terbitkan Tagihan, Saldo Awal, Syarat Ujian, PIN Ujian Siswa,
Kalender Sekolah, Tindak Lanjut BK, Penilaian Karakter, Tampilan) diletakkan di akhir grup terdekat.
